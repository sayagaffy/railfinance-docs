# Overview

Modul Keuangan dalam Internal System RailFinance mencakup berbagai proses verifikasi dan manajemen UMDS (Uang Muka Dinas Sementara) serta verifikasi pendanaan eksternal.

Dokumentasi ini mencakup panduan penggunaan untuk fitur-fitur berikut:

## Menu Internal

### [Verifikasi Dokumen Persyaratan Internal](verifikasi-dokumen-keuangan)

Panduan untuk memverifikasi dokumen persyaratan internal, termasuk proses assign user, verifikasi, dan penolakan dokumen.

### [Internal UMDS](umds-keuangan)

Panduan lengkap untuk manajemen UMDS, mulai dari pencairan, pertanggungjawaban, revisi, hingga penghapusan dan approval.

### [Verifikasi Pendanaan Eksternal](verifikasi-pendanaan-keuangan)

Panduan untuk verifikasi pengajuan dana dari pihak eksternal dan evaluasi anggaran.

### [Verifikasi Eksternal (Kontrak)](verifikasi-kontrak-keuangan)

Panduan untuk verifikasi pembayaran kontrak eksternal, termasuk proses assign dan approval.
