# Verifikasi Eksternal (Kontrak)

Halaman ini berisi panduan untuk verifikasi pembayaran kontrak eksternal.

## Melakukan Assign

1.  Buka aplikasi dan login.
    ![Login](/img/railfinance/keuangan/media/image606.png)
    ![Login](/img/railfinance/keuangan/media/image607.png)
    ![Login](/img/railfinance/keuangan/media/image608.png)

2.  Pilih menu **Verifikasi Eksternal (Kontrak)**, lalu klik **Pembayaran Menunggu Verifikasi**.
    ![Menu](/img/railfinance/keuangan/media/image609.png)
    ![Menu](/img/railfinance/keuangan/media/image610.png)

3.  Pada daftar **Verifikasi Pembayaran Eksternal**, klik **icon assign**.
    ![Assign](/img/railfinance/keuangan/media/image611.png)
    ![Assign](/img/railfinance/keuangan/media/image612.png)

4.  Tampil popup list user. Cari nama user, klik **Nama User**, lalu klik **Submit**.
    :::tip
    Assign ke nama anda sendiri agar bisa melakukan approval.
    :::
    ![List User](/img/railfinance/keuangan/media/image613.png)
    ![Submit](/img/railfinance/keuangan/media/image614.png)
    ![Submit](/img/railfinance/keuangan/media/image615.png)
    ![Submit](/img/railfinance/keuangan/media/image616.png)
    ![Submit](/img/railfinance/keuangan/media/image617.png)

5.  Tampil popup konfirmasi Assign, klik **Ya, Assign**.
    ![Konfirmasi](/img/railfinance/keuangan/media/image618.png)

6.  Tampil popup berhasil di assign.
    ![Berhasil](/img/railfinance/keuangan/media/image619.png)

7.  User yang memproses akan tampil namanya pada kolom **status**.
    ![Status](/img/railfinance/keuangan/media/image620.png)
    ![Status](/img/railfinance/keuangan/media/image621.png)

## Melakukan Approval

1.  Buka menu **Verifikasi Eksternal (Kontrak)** -> **Pembayaran Menunggu Verifikasi**.
    ![Menu](/img/railfinance/keuangan/media/image622.png)
    ![Menu](/img/railfinance/keuangan/media/image623.png)
    ![Menu](/img/railfinance/keuangan/media/image624.png)
    ![Menu](/img/railfinance/keuangan/media/image625.png)
    ![Menu](/img/railfinance/keuangan/media/image626.png)

2.  Lihat **status**. Jika sudah diproses oleh nama sendiri, klik **Icon Jempol**.
    ![Approval](/img/railfinance/keuangan/media/image627.png)
    ![Approval](/img/railfinance/keuangan/media/image628.png)

3.  Pada halaman Approval, pastikan data dokumen benar. Klik **Approval Manager Keuangan**.
    ![Approve](/img/railfinance/keuangan/media/image629.png)
    ![Approve](/img/railfinance/keuangan/media/image630.png)

4.  Konfirmasi dengan klik **Ya, Approve**.
    ![Konfirmasi](/img/railfinance/keuangan/media/image631.png)
    ![Konfirmasi](/img/railfinance/keuangan/media/image632.png)

5.  Pembayaran berhasil disetujui. Klik **OK**.
    ![Berhasil](/img/railfinance/keuangan/media/image633.png)
    ![Berhasil](/img/railfinance/keuangan/media/image634.png)

6.  Data masuk ke menu **Pembayaran Sudah Verifikasi**, Status menjadi **Menunggu Approval Pajak**.
    ![Selesai](/img/railfinance/keuangan/media/image635.png)
