# Internal UMDS

Halaman ini berisi panduan penggunaan menu Internal UMDS (Uang Muka Dinas Sementara), termasuk pencairan normal, penggantian, pertanggungjawaban, revisi, dan penghapusan.

## Pencairan UMDS - Normal

1.  Buka aplikasi Railfinance dan login.
    ![Login](/img/railfinance/keuangan/media/image74.png)
    ![Login](/img/railfinance/keuangan/media/image75.png)
    ![Login](/img/railfinance/keuangan/media/image76.png)

2.  Pilih menu **Internal (UMDS)**.
    ![Menu](/img/railfinance/keuangan/media/image77.png)
    ![Menu](/img/railfinance/keuangan/media/image78.png)

3.  Pada halaman list **Internal (UMDS)**, klik tombol **Tambah**.
    ![Tambah](/img/railfinance/keuangan/media/image79.png)
    ![Tambah](/img/railfinance/keuangan/media/image80.png)

4.  Tampil Popup, pilih **Pencairan UMDS – Normal** (pastikan terceklis), lalu klik **Lanjut**.
    ![Pilih UMDS Normal](/img/railfinance/keuangan/media/image81.png)
    ![Pilih UMDS Normal](/img/railfinance/keuangan/media/image82.png)

5.  Masukkan **Nomor NPD/PR** dan **Tahun**, lalu klik tombol **Ambil Data**.
    ![Ambil Data](/img/railfinance/keuangan/media/image83.png)
    ![Ambil Data](/img/railfinance/keuangan/media/image84.png)
    ![Ambil Data](/img/railfinance/keuangan/media/image85.png)
    ![Ambil Data](/img/railfinance/keuangan/media/image86.png)

6.  Jika **Nomor NPD/PR** valid, data akan muncul. Klik **Simpan**.
    ![Simpan](/img/railfinance/keuangan/media/image87.png)
    ![Simpan](/img/railfinance/keuangan/media/image88.png)

7.  Muncul popup list dokumen yang diperlukan (lihat **Catatan**). Jika diperlukan tambahan dokumen, klik dokumen tersebut hingga berwarna biru, lalu klik **Terapkan**.
    ![Pilih Dokumen](/img/railfinance/keuangan/media/image89.png)
    ![Pilih Dokumen](/img/railfinance/keuangan/media/image90.png)
    ![Pilih Dokumen](/img/railfinance/keuangan/media/image91.png)

8.  Klik tombol **Lanjut** untuk meneruskan ke halaman unggah dokumen.
    :::tip
    Jika ada penambahan atau perubahan dokumen, bisa klik Ikon **Pensil Atur**.
    :::
    ![Lanjut](/img/railfinance/keuangan/media/image92.png)
    ![Lanjut](/img/railfinance/keuangan/media/image93.png)
    ![Lanjut](/img/railfinance/keuangan/media/image94.png)

9.  Pada halaman unggah dokumen, pilih dan klik tab dokumen yang akan diunggah.
    ![Halaman Unggah](/img/railfinance/keuangan/media/image95.png)
    ![Halaman Unggah](/img/railfinance/keuangan/media/image96.png)
    ![Halaman Unggah](/img/railfinance/keuangan/media/image97.png)
    ![Halaman Unggah](/img/railfinance/keuangan/media/image98.png)

10. **Upload RAB**: Klik tab **RAB**, klik tombol **Pilih File**, pilih file yang sesuai.
    ![Upload RAB](/img/railfinance/keuangan/media/image99.png)
    ![Upload RAB](/img/railfinance/keuangan/media/image100.png)
    ![Upload RAB](/img/railfinance/keuangan/media/image101.png)

11. Tampil data RAB, klik **Simpan**.
    ![Simpan RAB](/img/railfinance/keuangan/media/image102.png)
    ![Simpan RAB](/img/railfinance/keuangan/media/image103.png)

12. **Upload Justifikasi UMDS**: Klik tab **Justifikasi UMDS**, klik tombol **Pilih File**, pilih file.
    ![Upload Justifikasi](/img/railfinance/keuangan/media/image104.png)
    ![Upload Justifikasi](/img/railfinance/keuangan/media/image105.png)
    ![Upload Justifikasi](/img/railfinance/keuangan/media/image106.png)

13. Tampil data Justifikasi UMDS, klik **Simpan**.
    ![Simpan Justifikasi](/img/railfinance/keuangan/media/image107.png)
    ![Simpan Justifikasi](/img/railfinance/keuangan/media/image108.png)

14. **Upload NPD/PR**: Klik tab **NPD/PR**, klik tombol **Pilih File**, pilih file.
    :::warning
    Nama dokumen NPD/PR harus sesuai dengan nomor **NDP/PR** (contoh: **1900007145.pdf**).
    :::
    ![Upload NPD](/img/railfinance/keuangan/media/image109.png)
    ![Upload NPD](/img/railfinance/keuangan/media/image110.png)
    ![Upload NPD](/img/railfinance/keuangan/media/image111.png)

15. Tampil data NPD/PR, klik **Simpan**. Jika semua dokumen sudah diupload, klik **Lanjut**.
    ![Simpan NPD](/img/railfinance/keuangan/media/image112.png)
    ![Simpan NPD](/img/railfinance/keuangan/media/image113.png)
    ![Simpan NPD](/img/railfinance/keuangan/media/image114.png)

16. Pada halaman **Pratinjau**, centang checkbox **Baca Syarat dan ketentuan terkait pengajuan**.
    ![Pratinjau](/img/railfinance/keuangan/media/image115.png)
    ![Pratinjau](/img/railfinance/keuangan/media/image116.png)

17. Pastikan syarat terpenuhi, lalu klik tombol **Setuju**.
    ![Setuju](/img/railfinance/keuangan/media/image117.png)
    ![Setuju](/img/railfinance/keuangan/media/image118.png)

18. Klik tombol **Submit**.
    ![Submit](/img/railfinance/keuangan/media/image119.png)
    ![Submit](/img/railfinance/keuangan/media/image120.png)

19. Muncul list user pemeriksa. Cari nama user pemeriksa, klik **Nama User**, kemudian klik **Submit**.
    :::info
    Pemeriksa bersifat opsional. Jika tidak perlu, bisa klik tombol **Lewati Pemeriksa**.
    :::
    ![Pilih Pemeriksa](/img/railfinance/keuangan/media/image121.png)
    ![Pilih Pemeriksa](/img/railfinance/keuangan/media/image122.png)
    ![Pilih Pemeriksa](/img/railfinance/keuangan/media/image123.png)
    ![Pilih Pemeriksa](/img/railfinance/keuangan/media/image124.png)

20. Konfirmasi dengan klik tombol **Ya Submit**.
    ![Konfirmasi](/img/railfinance/keuangan/media/image125.png)
    ![Konfirmasi](/img/railfinance/keuangan/media/image126.png)

21. Pengajuan akan muncul di list. Tunggu proses **Approval Atasan** atau **Approval Pemeriksa**.
    ![Selesai](/img/railfinance/keuangan/media/image127.png)
    ![Selesai](/img/railfinance/keuangan/media/image128.png)
    ![Selesai](/img/railfinance/keuangan/media/image129.png)

    ![Submit Revisi](/img/railfinance/keuangan/media/image262.png)
    ![Submit Revisi](/img/railfinance/keuangan/media/image263.png)

    ![Pemeriksa](/img/railfinance/keuangan/media/image268.png)

    ![Selesai](/img/railfinance/keuangan/media/image274.png)
