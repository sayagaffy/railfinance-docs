# Unit Atasan (Internal)

Selamat datang di dokumentasi **Unit Atasan** untuk sistem internal Railfinance. Modul ini dirancang untuk membantu Unit Atasan dalam mengelola dan memverifikasi pengajuan UMDS (Uang Muka Dinas Sementara).

## Fitur Utama

### [UMDS](umds-unit-atasan)

Panduan lengkap untuk manajemen UMDS, mencakup:

- **Approval**: Menyetujui pengajuan UMDS dari unit pengaju
- **Reject**: Menolak pengajuan dengan memberikan keterangan
- **Melihat Dokumen**: Memeriksa dokumen persyaratan yang diajukan
