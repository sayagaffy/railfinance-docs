# Unit Pengaju (Internal)

Selamat datang di dokumentasi **Unit Pengaju** untuk sistem internal Railfinance. Modul ini dirancang untuk membantu Unit Pengaju dalam mengajukan dan mengelola UMDS (Uang Muka Dinas Sementara).

## Fitur Utama

### [UMDS](umds-unit-pengaju)

Panduan lengkap untuk pengajuan UMDS, mencakup:

- **Pencairan UMDS**: Normal dan Penggantian (Reimbursement)
- **Pertanggungjawaban**: Pelaporan penggunaan dana (G61)
- **Revisi**: Memperbaiki pengajuan yang dikembalikan
- **Hapus**: Menghapus pengajuan dengan status Draft
- **Melihat Dokumen**: Memeriksa status dan detail pengajuan
