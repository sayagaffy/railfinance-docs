# Verifikasi Pendanaan Eksternal

Menu ini digunakan untuk verifikasi pendanaan eksternal, termasuk approval, tolak, assign, dan evaluasi anggaran.

## Approve Atasan Pengajuan Dana

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**.
    ![Image 644](/img/railfinance/manager-keuangan/media/image644.png)
    ![Image 645](/img/railfinance/manager-keuangan/media/image645.png)![Image 646](/img/railfinance/manager-keuangan/media/image646.png)

2.  Jika login berhasil Sistem akan menampilkan halaman dashboard. Lalu pilih menu **Verifikasi Pendanaan Eksternal**, klik **Menunggu Verifikasi**.
    ![Image 647](/img/railfinance/manager-keuangan/media/image647.png)![Image 648](/img/railfinance/manager-keuangan/media/image648.png)

3.  Tampil halaman list **Verifikasi Pendanaan Eksternal,** lihat **status dokumen,** lalu klik **icon Mata**.
    ![Image 649](/img/railfinance/manager-keuangan/media/image649.png)![Image 650](/img/railfinance/manager-keuangan/media/image650.png)![Image 651](/img/railfinance/manager-keuangan/media/image651.png)

4.  Tampil halaman detail Pengajuan, Periksa data serta dokumen pada tabel **File,** jika sudah sesuai klik **Setuju**.
    ![Image 652](/img/railfinance/manager-keuangan/media/image652.png)
    ![Image 653](/img/railfinance/manager-keuangan/media/image653.png)![Image 654](/img/railfinance/manager-keuangan/media/image654.png)

5.  Jika berhasil terdapat pemberitahuan Pengajuan dana berhasil disetujui.
    ![Image 655](/img/railfinance/manager-keuangan/media/image655.png)
    ![Image 656](/img/railfinance/manager-keuangan/media/image656.png)

6.  Pengajuan yang telah **disetujui sebagai atasan** akan berubah menjadi **evaluasi anggaran**, yang dapat dilihat pada **status dokumen.**
    Catatan: Jika sudah melakukan verifikasi atasan dapat langsung melakukan evaluasi anggaran.
    ![Image 657](/img/railfinance/manager-keuangan/media/image657.png)![Image 658](/img/railfinance/manager-keuangan/media/image658.png)![Image 659](/img/railfinance/manager-keuangan/media/image659.png)

    ![Image 698](/img/railfinance/manager-keuangan/media/image698.png)

5.  Lalu klik button **upload dokumen persetujuan dana**.
