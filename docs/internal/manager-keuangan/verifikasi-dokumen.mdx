# Verifikasi Dokumen Persyaratan Internal

Menu ini digunakan untuk melakukan assign user dan verifikasi dokumen persyaratan internal.

## Melakukan Assign User

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**. Lalu klik Button **Login**.
    ![Image 256](/img/railfinance/manager-keuangan/media/image256.png)![Image 257](/img/railfinance/manager-keuangan/media/image257.png)![Image 258](/img/railfinance/manager-keuangan/media/image258.png)![Image 259](/img/railfinance/manager-keuangan/media/image259.png)

2.  Jika login berhasil Sistem akan menampilkan halaman **dashboard**. Lalu pilih menu **Verifikasi & Evaluasi Dokumen Persyaratan Internal**, lalu klik menu **Menunggu**.
    ![Image 260](/img/railfinance/manager-keuangan/media/image260.png)
    ![Image 261](/img/railfinance/manager-keuangan/media/image261.png)

3.  Tampil halaman list pengajuan. klik button **Assign** yang **berwarna biru** untuk memproses pengajuan.
    ![Image 262](/img/railfinance/manager-keuangan/media/image262.png)![Image 263](/img/railfinance/manager-keuangan/media/image263.png)

4.  Tampil Popup **List User**.
    ![Image 264](/img/railfinance/manager-keuangan/media/image264.png)

5.  Cari nama user yang bersangkutan/bertanggung jawab untuk memproses pengajuan tersebut. Lalu **Cari user** klik **Nama User** dan klik button **Assign**.
    Catatan: Assign ini bisa dilakukan ke nama sendiri.
    ![Image 265](/img/railfinance/manager-keuangan/media/image265.png)
    ![Image 266](/img/railfinance/manager-keuangan/media/image266.png)![Image 267](/img/railfinance/manager-keuangan/media/image267.png)![Image 268](/img/railfinance/manager-keuangan/media/image268.png)

6.  Tampil popup konfirmasi lalu klik button **Ya, Assign**.
    ![Image 269](/img/railfinance/manager-keuangan/media/image269.png)
    ![Image 270](/img/railfinance/manager-keuangan/media/image270.png)

7.  Tampil popup informasi berhasil assign user lalu klik button **Ok**.
    ![Image 271](/img/railfinance/manager-keuangan/media/image271.png)
    ![Image 272](/img/railfinance/manager-keuangan/media/image272.png)

8.  Setelah selesai assign maka label status akan berubah menjadi **diproses nama_user**.
    Catatan: Jika ingin mengganti user yang memproses pengajuan tersebut, Klik kembali button **Assign** dan ulangi langkah yang tadi.
    ![Image 273](/img/railfinance/manager-keuangan/media/image273.png)
    ![Image 274](/img/railfinance/manager-keuangan/media/image274.png)

## Evaluasi RAB

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**. Lalu klik Button **Login**.
    ![Image 275](/img/railfinance/manager-keuangan/media/image275.png)![Image 276](/img/railfinance/manager-keuangan/media/image276.png)![Image 277](/img/railfinance/manager-keuangan/media/image277.png)![Image 278](/img/railfinance/manager-keuangan/media/image278.png)

2.  Jika login berhasil Sistem akan menampilkan halaman **dashboard**. Lalu pilih menu **Verifikasi & Evaluasi Dokumen Persyaratan Internal**, lalu klik menu **Menunggu**.

3.  Tampil halaman list pengajuan. klik button **View** yang berwarna kuning. Evaluasi RAB hanya bisa dilakukan ketika sudah **Assign** **diproses** oleh **nama sendiri**.

    ![Image 282](/img/railfinance/manager-keuangan/media/image282.png)

4.  Tampil Halaman **Approval**, Periksa dan lihat dokumen **RAB** jika terjadi kesalahan, Klik button **Evaluasi RAB.**
    ![Image 283](/img/railfinance/manager-keuangan/media/image283.png)
    ![Image 284](/img/railfinance/manager-keuangan/media/image284.png)![Image 285](/img/railfinance/manager-keuangan/media/image285.png)

5.  Tampil halaman **Evaluasi Dokumen RAB**, lalu klik **Upload** untuk memasukan dokumen RAB baru.
    ![Image 286](/img/railfinance/manager-keuangan/media/image286.png)
    ![Image 287](/img/railfinance/manager-keuangan/media/image287.png)

6.  Tampil popup **Dokumen Berhasil**, lalu klik button **OK.**
    ![Image 288](/img/railfinance/manager-keuangan/media/image288.png)
    ![Image 289](/img/railfinance/manager-keuangan/media/image289.png)

7.  Tampil data dokumen RAB, periksa kembali data, berikan **Keterangan Revisi** jika dibutuhkan, lalu klik **Submit Evaluasi**.
    ![Image 290](/img/railfinance/manager-keuangan/media/image290.png)
    ![Image 291](/img/railfinance/manager-keuangan/media/image291.png)![Image 292](/img/railfinance/manager-keuangan/media/image292.png)

8.  Tampil halaman **Approval**, diatas dokumen **RAB** muncul kata **evaluasi**, yang berarti evaluasi RAB telah dilakukan.
    ![Image 293](/img/railfinance/manager-keuangan/media/image293.png)
    ![Image 294](/img/railfinance/manager-keuangan/media/image294.png)

    ![Image 374](/img/railfinance/manager-keuangan/media/image374.png)

18. Dokumen berhasil **Terverifikasi**, dapat dilihat pada status dokumen.

19. Dokumen pengajuan yang **terverifikasi** dapat dilihat pada menu **Sudah**, lalu **Search No.kontrak** dan status akan jadi **Selesai**.
