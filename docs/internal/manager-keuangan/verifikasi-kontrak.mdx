# Verifikasi Eksternal (Kontrak)

Menu ini digunakan untuk verifikasi pembayaran eksternal (kontrak), termasuk assign, approval, dan reject.

## Melakukan Assign

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**.
    ![Image 778](/img/railfinance/manager-keuangan/media/image778.png)
    ![Image 779](/img/railfinance/manager-keuangan/media/image779.png)![Image 780](/img/railfinance/manager-keuangan/media/image780.png)

2.  Jika login berhasil Sistem akan menampilkan halaman dashboard. Lalu pilih menu **Verifikasi Eksternal (Kontrak)**, klik **Pembayaran Menunggu Verifikasi**.
    ![Image 781](/img/railfinance/manager-keuangan/media/image781.png)![Image 782](/img/railfinance/manager-keuangan/media/image782.png)

3.  Tampil halaman list **Verifikasi Pembayaran Eksternal,** lihat **status dokumen,** lalu klik **icon assign**.
    ![Image 783](/img/railfinance/manager-keuangan/media/image783.png)![Image 784](/img/railfinance/manager-keuangan/media/image784.png)

4.  Tampil popup list user untuk melakukan assign.
    ![Image 785](/img/railfinance/manager-keuangan/media/image785.png)

5.  Cari nama user untuk memproses pengajuan, lalu klik **Nama User** tersebut kemudian klik **Submit**.
    Catatan: Assign ke nama anda sendiri agar bisa melakukan approval.
    ![Image 786](/img/railfinance/manager-keuangan/media/image786.png)
    ![Image 787](/img/railfinance/manager-keuangan/media/image787.png)![Image 788](/img/railfinance/manager-keuangan/media/image788.png)![Image 789](/img/railfinance/manager-keuangan/media/image789.png)

6.  Tampil popup konfirmasi Assign, klik **Ya, Assign**.
    ![Image 790](/img/railfinance/manager-keuangan/media/image790.png)![Image 791](/img/railfinance/manager-keuangan/media/image791.png)

7.  Tampil popup berhasil di assign.
    ![Image 792](/img/railfinance/manager-keuangan/media/image792.png)

8.  Maka user yang memproses akan tampil namanya pada **status**.
    ![Image 793](/img/railfinance/manager-keuangan/media/image793.png)![Image 794](/img/railfinance/manager-keuangan/media/image794.png)

## Melakukan Approval

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**.
    ![Image 795](/img/railfinance/manager-keuangan/media/image795.png)
    ![Image 796](/img/railfinance/manager-keuangan/media/image796.png)![Image 797](/img/railfinance/manager-keuangan/media/image797.png)

2.  Jika login berhasil Sistem akan menampilkan halaman dashboard. Lalu pilih menu **Verifikasi Eksternal (Kontrak)**, klik **Pembayaran Menunggu Verifikasi**.
    ![Image 798](/img/railfinance/manager-keuangan/media/image798.png)![Image 799](/img/railfinance/manager-keuangan/media/image799.png)

3.  Tampil halaman list **Verifikasi Pembayaran Eksternal,** lihat **status** jika sudah diprose oleh nama sendiri maka dapat melakukan approval, klik **Icon Jempol.**
    ![Image 800](/img/railfinance/manager-keuangan/media/image800.png)![Image 801](/img/railfinance/manager-keuangan/media/image801.png)

4.  Tampil halaman Approval, Klik **Calculate By AI** jika ingin melakukan perhitungan pajak, atau dapat langsung klik **Approval Manager Keuangan**.
    Catatan: Jika perhitungan pajak belum dilakukan, tombol jadi Calculate by AI. Setelah perhitungan pernah dilakukan, tombol akan berubah menjadi Edit Pajak.
    ![Image 802](/img/railfinance/manager-keuangan/media/image802.png)
    ![Image 803](/img/railfinance/manager-keuangan/media/image803.png)

5.  Tampil halaman perhitungan, Periksa data kembali, lalu klik **Calculate by AI**.
    ![Image 804](/img/railfinance/manager-keuangan/media/image804.png)![Image 805](/img/railfinance/manager-keuangan/media/image805.png)

6.  Tunggu hingga proses perhitungan selesai.
    ![Image 806](/img/railfinance/manager-keuangan/media/image806.png)

7.  Jika tampil popup **Berhasil,** maka perhitungan sudah selesai dihitung.
    ![Image 807](/img/railfinance/manager-keuangan/media/image807.png)

8.  Periksa data perhitungan, lalu klik **Simpan** jika sudah selesai.
    ![Image 808](/img/railfinance/manager-keuangan/media/image808.png)![Image 809](/img/railfinance/manager-keuangan/media/image809.png)

9.  Jika ada perhitungan yang ingin diubah, klik **Edit Pajak.** Jika sudah sesuai klik **Approval Manager Keuangan.**
    ![Image 810](/img/railfinance/manager-keuangan/media/image810.png)![Image 811](/img/railfinance/manager-keuangan/media/image811.png)

10. tampil popup Konfirmasi Approval, klik **Ya, Approve**.
    ![Image 812](/img/railfinance/manager-keuangan/media/image812.png)![Image 813](/img/railfinance/manager-keuangan/media/image813.png)

11. Tampil popup Pembayaran berhasil disetujui, Klik **OK**.
    ![Image 814](/img/railfinance/manager-keuangan/media/image814.png)![Image 815](/img/railfinance/manager-keuangan/media/image815.png)

12. Jika Berhasil data akan masuk ke menu **Pembayaran Sudah Verifikasi**.
    ![Image 816](/img/railfinance/manager-keuangan/media/image816.png)

## Melakukan Reject

1.  Buka aplikasi Railfinance. Masukkan **NIPP** dan **Password**.
    ![Image 817](/img/railfinance/manager-keuangan/media/image817.png)
    ![Image 818](/img/railfinance/manager-keuangan/media/image818.png)![Image 819](/img/railfinance/manager-keuangan/media/image819.png)

2.  Jika login berhasil Sistem akan menampilkan halaman dashboard. Lalu pilih menu **Verifikasi Eksternal (Kontrak)**, klik **Pembayaran Menunggu Verifikasi**.
    ![Image 820](/img/railfinance/manager-keuangan/media/image820.png)![Image 821](/img/railfinance/manager-keuangan/media/image821.png)

3.  Tampil halaman list **Verifikasi Pembayaran Eksternal,** lihat **status** jika sudah diprose oleh nama sendiri maka dapat melakukan approval, klik **Icon Jempol.**
    ![Image 822](/img/railfinance/manager-keuangan/media/image822.png)![Image 823](/img/railfinance/manager-keuangan/media/image823.png)

4.  Tampil halaman Approval, Pastikan data dokumen sudah benar dan sesuai, klik **Reject**.
    ![Image 824](/img/railfinance/manager-keuangan/media/image824.png)
    ![Image 825](/img/railfinance/manager-keuangan/media/image825.png)

5.  Tampil popup Reject, diharuskan **memasukkan keterangan**, lalu klik **Ya, Reject**.
    ![Image 826](/img/railfinance/manager-keuangan/media/image826.png)
    ![Image 827](/img/railfinance/manager-keuangan/media/image827.png)![Image 828](/img/railfinance/manager-keuangan/media/image828.png)

6.  Tampil popup Pembayaran berhasil ditolak, Klik **OK**.
    ![Image 829](/img/railfinance/manager-keuangan/media/image829.png)
    ![Image 830](/img/railfinance/manager-keuangan/media/image830.png)

7.  Jika berhasil melakukan reject, terdapat pemberitahuan **pembayaran berhasil ditolak**.
    ![Image 831](/img/railfinance/manager-keuangan/media/image831.png)
    ![Image 832](/img/railfinance/manager-keuangan/media/image832.png)
