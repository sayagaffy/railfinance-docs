# Manager Keuangan - Internal

Dokumen ini menjelaskan panduan penggunaan aplikasi Railfinance untuk User **Manager Keuangan** pada modul **Internal**.

Modul ini mencakup:

- **[Internal UMDS](./umds)**: Proses pencairan, pertanggungjawaban, revisi, hapus, dan approval UMDS.
- **[Verifikasi Dokumen](./verifikasi-dokumen)**: Verifikasi dokumen persyaratan internal, evaluasi RAB, dan evaluasi UMDS.
- **[Verifikasi Pendanaan](./verifikasi-pendanaan)**: Verifikasi pendanaan eksternal.
- **[Verifikasi Kontrak](./verifikasi-kontrak)**: Verifikasi eksternal kontrak.
