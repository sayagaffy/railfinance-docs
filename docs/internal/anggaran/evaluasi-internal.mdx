:::info Modul Verifikasi
Halaman ini berisi panduan untuk proses evaluasi dan verifikasi dokumen persyaratan internal UMDS.
:::

## Menu Verifikasi Dokumen

Evaluasi dilakukan melalui menu **Evaluasi Dokumen Persyaratan Internal**.

1. Masuk ke aplikasi Railfinance.
2. Pilih menu **Evaluasi Dokumen Persyaratan Internal** > **Menunggu Evaluasi**.

---

### A. Melakukan Assign User

Sebelum dokumen dievaluasi, dokumen harus di-_assign_ (diserahkan) kepada user pemroses (bisa diri sendiri).

1. Pada list pengajuan, klik tombol **Assign** (berwarna biru).
   ![](/img/railfinance/anggaran/media/image88.png)
2. Cari nama user yang akan memproses pengajuan (bisa nama Anda sendiri).
3. Klik pada nama user tersebut, lalu klik tombol **Assign**.
   ![](/img/railfinance/anggaran/media/image89.png)
4. Klik **Ya, Assign** pada popup konfirmasi.
   ![](/img/railfinance/anggaran/media/image154.png)
5. Status pengajuan akan berubah menjadi **Diproses oleh [Nama User]**.

---

### B. Evaluasi RAB

Evaluasi RAB hanya dapat dilakukan jika pengajuan sudah di-_assign_ ke diri sendiri.

1. Klik tombol **View** (ikon mata kuning) pada pengajuan yang sudah di-assign.
   ![](/img/railfinance/anggaran/media/image48.png)
2. Periksa dokumen RAB pada tab dokumen.
3. Jika terdapat kesalahan atau revisi pada RAB:
   - Klik tombol **Evaluasi RAB**.
   - Upload file RAB baru/revisi dengan klik **Upload**.
     ![](/img/railfinance/anggaran/media/image125.png)
   - Klik **Submit Evaluasi**.
     ![](/img/railfinance/anggaran/media/image130.png)
4. Dokumen RAB yang sudah dievaluasi akan ditandai dengan label "Evaluasi".

---

### C. Memberi Catatan

Jika ada kekurangan atau hal yang perlu dikonfirmasi namun tidak memerlukan penolakan dokumen.

1. Klik tombol **Catatan** pada halaman Approval.
   ![](/img/railfinance/anggaran/media/image141.png)
2. Masukkan keterangan catatan pada kolom yang tersedia.
   ![](/img/railfinance/anggaran/media/image131.png)
3. Klik **Ya, Simpan Catatan**.
4. _Catatan: Setelah memberi catatan, status pengajuan mungkin akan kembali ke awal dan perlu di-assign ulang jika proses berlanjut._

---

### D. Reject Dokumen

Jika dokumen pengajuan tidak valid atau menyalahi aturan.

1. Klik tombol **Reject** pada halaman Approval.
   ![](/img/railfinance/anggaran/media/image141.png)
2. Masukkan alasan penolakan pada kolom keterangan (Wajib diisi).
   ![](/img/railfinance/anggaran/media/image142.png)
3. Klik **Ya, Reject**.
4. Status pengajuan akan berubah menjadi **Ditolak** dan dikembalikan ke pengaju.

---

### E. Approval / Verify Dokumen

Jika seluruh dokumen sudah valid dan sesuai.

1. Klik tombol **Verify** pada halaman Approval.
   ![](/img/railfinance/anggaran/media/image141.png)
2. Unggah dokumen **Persetujuan Dana**.
   - Pastikan nomor persetujuan dana sesuai.
     ![](/img/railfinance/anggaran/media/image145.png)
3. Klik **Approval Manager** (atau tombol Approval sesuai level Anda).
   ![](/img/railfinance/anggaran/media/image153.png)
4. Klik **Submit**.
   ![](/img/railfinance/anggaran/media/image151.png)
5. Status pengajuan akan berubah menjadi **Verified By Anggaran** (atau status setara).
