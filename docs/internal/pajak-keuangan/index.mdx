# Pajak & Keuangan - Internal

Dokumen ini menjelaskan panduan penggunaan aplikasi Railfinance untuk User **Pajak & Keuangan ** pada modul** Internal **.

Modul ini mencakup:

-**[Verifikasi Dokumen](./verifikasi-dokumen) **: Proses verifikasi UMDS Pertanggung Jawaban, revisi, dan pajak lainnya.
-**[Internal UMDS](./umds)**: Manajemen pencairan dan pertanggungjawaban UMDS.
